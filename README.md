# Mira public website

Public support, privacy, terms, and scoring methodology for the Mira iOS app.

Website: https://lbarnhart.github.io/Mira8-site/

GitHub Pages publishes the `main` branch from the repository root with Jekyll and the Minima theme. This repository contains website content only. App source, signing material, and local configuration belong in the private app repository.

The website sources are maintained in the private app repository's `docs/` directory. Copy those six source files into this repository when publishing a reviewed update. Preserve the legal pages' effective dates unless their content changes.
